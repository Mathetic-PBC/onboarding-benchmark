# uist26-talk

Slides and figure scripts for the TutorTrace talk at UIST 2026 (session "Learning & Tutoring", Oct 7).

- `slides/`: reveal.js deck written in Markdown (`talk.md`); open `slides/index.html` via a local server
- `figures/`: scripts that render the slide figures into `slides/img/` (colors from `palette.py`, same as the paper)
- `tests/`: smoke tests for the figure scripts (`python -m pytest`)
