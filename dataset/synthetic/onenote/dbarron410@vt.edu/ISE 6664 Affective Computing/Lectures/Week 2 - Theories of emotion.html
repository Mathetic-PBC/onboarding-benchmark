wk2 — theories (Jan 20)

basic / discrete emotions

  • Ekman: small set of universal categories w/ distinct expressions
  • critique: cross-cultural recognition studies used forced choice → inflated agreement

dimensional

  • Russell circumplex: valence × arousal
  • PAD adds dominance
  • nice for continuous annotation (FEELtrace-style sliders)
  • frustration ≈ negative valence, moderate–high arousal; boredom ≈ negative valence, low arousal — these get confused by text classifiers

appraisal theories

  • emotion = outcome of evaluating an event vs your goals (relevance, congruence, coping potential, agency)
  • frustration = goal blocked + you still think you could have done it → this maps really cleanly onto a student stuck on a bug
  • OCC model used a lot in agents bc it is implementable as rules

constructed emotion (Barrett)

  • categories are constructed from interoception + concepts, no fingerprints
  • implication for us: labels are always an interpretation, treat as annotator judgement not ground truth

Brooks: "pick the theory that matches your measurement, and say so in the paper." write that down for the project report.
