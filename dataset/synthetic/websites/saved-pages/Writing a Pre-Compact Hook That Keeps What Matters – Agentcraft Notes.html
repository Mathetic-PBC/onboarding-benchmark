Writing a Pre-Compact Hook That Keeps What Matters

By Sven Aldridge · July 30, 2026

Long coding sessions eventually fill the context window, and the agent compacts: it replaces the history with a summary. Summaries lose the details you need most, like the exact name of a failing test or an environment variable.

Hooks

Most agent CLIs expose a hook that runs before compaction. A hook script receives the session state and can add instructions to the summary prompt.

What to keep verbatim

  • The current task in one line, written by the human
  • File paths touched in this session
  • Failing test names and the last error message
  • Environment variable names (never values)

Measuring it

Run the same task several times with and without the hook and record context size before and after compaction and whether the task finished. Six runs will tell you if something is badly wrong; you need more to compare two good versions.
