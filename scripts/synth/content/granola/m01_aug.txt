### Repo setup (started this week)

- Monorepo decided: `apps/web`, `workers/importers`, `packages/types`
- Shared `SourceItem` type: id, source, source_id, title, created_at, modified_at, content_hash, parts[]
- One importer per source; each yields items, never writes to the DB directly
- CI: typecheck + importer fixtures on every PR; no deploy pipeline yet

### Importer order

1. Claude export (JSON) — David has his own export to test on
2. ChatGPT export — conversation tree flattening needed (branches from edited messages)
3. Zotero (local sqlite + storage folder)
4. Local PDFs (watch ~/Downloads and ~/Desktop/papers)

### Dedupe design (first cut)

- Exact: sha256 over normalized bytes → same item, merge parts
- Near: title + first-page text similarity > 0.9 → "possible duplicate" badge, never auto-merge
- Keep both source paths so the trail can say "found in Zotero and Downloads"
