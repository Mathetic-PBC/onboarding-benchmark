### What the two pilots told us about import

- **Omissions:** Priya's ~140 Claude chats (split export), Daniel's Granola notes (no connector), 4 empty conversations dropped silently
- **Wrong items:** Notion ids in titles; flattened hierarchy; database rows as separate items
- **Duplicates:** publisher vs arXiv PDFs; same paper in Zotero, Downloads and a Slack DM
- Every one of these was found by a user, live — not by us

### Decision: measure import before redesigning it

- Build an import benchmark: a realistic researcher's full footprint across tools, with a hand-labelled "what should come in" list
- Score each import on: items missed, items that shouldn't be there, duplicates, wrong project grouping
- Use David's own accounts as the base (he has the messiest footprint), plus generated data for tools he barely uses
- Every bug from the pilots becomes a test case

### Connect screen v2

- "Other" → "Upload files"; new "Request a source" tile (votes)
- Coming soon list: Notion, Granola, Google Drive
- After connect: per-source preview ("we found 553 conversations, 9 projects") before importing

### Order of work

1. Benchmark skeleton + labels for David's data (this weekend)
2. Run current importer against it → baseline numbers
3. Notion connector (hierarchy + titles), then Granola
4. Re-run; report numbers to pilots and Marcus
